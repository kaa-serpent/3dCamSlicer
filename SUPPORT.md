# RotaryCAM Support

RotaryCAM is an early-stage, source-available project and does not provide guaranteed support
or verified controller compatibility.

- Ask usage and design questions in [GitHub Discussions](https://github.com/kaa-serpent/3dCamSlicer/discussions).
- Report reproducible defects with the bug-report issue form.
- Propose scoped enhancements with the feature-request form.
- Report vulnerabilities privately by following [SECURITY.md](SECURITY.md).

Before asking for help, include the RotaryCAM revision, Python version, operating system,
machine profile status, relevant project settings, and the smallest safe reproduction. Remove
proprietary models or machine data that you do not have permission to share.
